AC11.05 | Comprendre les structures algorithmiques de base et leur contexte d'usage

Le calcul de la distance de Jaccard repose sur des structures algorithmiques concrètes : des boucles imbriquées pour comparer tous les couples d'étudiants, des conditions pour tester l'appartenance à un ensemble, et une logique de comptage pour l'intersection et l'union. Implémenter la distance de Levenshtein avec un seuil d'arrêt prématuré m'a aussi appris l'importance de l'optimisation dans un algorithme.

Trace d'apprentissage
If car1 = car2 Then
    distance(i, j) = distance(i - 1, j - 1)
Else
    min1 = distance(i - 1, j) + 1
    min2 = distance(i, j - 1) + 1
    min3 = distance(i - 1, j - 1) + 1

    If min1 < min2 Then
        If min1 < min3 Then
            distance(i, j) = min1
        Else
            distance(i, j) = min3
        End If
    Else
        If min2 < min3 Then
            distance(i, j) = min2
        Else
            distance(i, j) = min3
        End If
    End If
End If

AC12.04 | Comprendre l'intérêt des synthèses numériques et graphiques pour mettre en évidence des liaisons entre variables

L'objectif de cet apprentissage était de savoir croiser deux variables pour analyser la manière dont elles s'influencent mutuellement. Dans cette SAÉ, l'enjeu était de modéliser la masse des viscères en fonction des dimensions des spécimens. Pour y parvenir, j'ai appris à combiner l'approche graphique et l'approche numérique. Le tracé des premiers nuages de points avec ggplot() a été indispensable pour observer la forme de la relation et orienter mes choix, comme l'application d'une transformation logarithmique lorsque la liaison n'était pas purement linéaire. C'est ensuite le calcul des indicateurs numériques, notamment à travers les résumés des modèles de régression (lm()), qui est venu valider scientifiquement ces observations visuelles en me fournissant les coefficients de pente et les mesures de précision. Cette démarche m'a démontré qu'on ne peut pas valider solidement la liaison entre deux variables sans coupler la perception globale du graphique à la rigueur des indicateurs chiffrés.

  geom_point(aes(color = Sex)) + # On colore par sexe pour l'analyse visuelle
  geom_smooth(method = "lm", se = FALSE, color = "blue") + # On ajoute la droite de régression en bleu pour tester le modèle linéaire

  xlab("Dimension 1 (mm)") + ylab("Masse des viscères (g)")
